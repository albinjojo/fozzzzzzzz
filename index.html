02. About

We build the platforms that empower students.

AJCE FOSS is a student collective advocating for software freedom, peer-to-peer collaboration, and build-centric learning.

Peer Learning

We learn from each other. No rigid syllabus or test scores—just code reviews, chat threads, and collaborative hacking sessions.

Open Source

We build tools, host Linux install festivals, compile custom packages, and push directly to open global repos.

Workshops

Hands-on crash courses covering everything from basic command utilities to advanced systems programming, UI, and docker containers.

Hackathons

Overnight sprints where student teams brainstorm, write scripts, share pizza, and demo real-working software.

04. Milestones

Where we have shipped.

A simple timeline tracking the evolution of the FOSS community at Amal Jyothi.

JANUARY 2025

Community Kickoff

Launched by a group of systems and web engineering students. Established our flat hierarchy culture and peer mentorship path.

APRIL 2025

First Linux Install Fest

Instructed over 60 students on disk partitions, custom boot managers, and configuring dotfile setups in the computer science labs.

OCTOBER 2025

Hacknight v1.0

Our inaugural 24-hour overnight code sprint. Generated 15 prototypes built completely by student teams.

FEBRUARY 2026

TinkerSpace Cooperation

Merged networks with TinkerHub to run unified, hands-on engineering programs across domains like web dev, embedded, and product design.
