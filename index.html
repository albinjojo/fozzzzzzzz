Our Culture

What We Do

We believe the best way to learn technology is by building things. No boring theory lectures - just hands-on sessions, peer collaboration, and open-source contribution.

Peer Learning

No formal classrooms. We teach each other by sharing resources, pair programming, and doing code reviews together.

Open Source

We build tools, host Linux Install Fests, configure terminal dotfiles, and commit code directly to open repos.

Workshops

Hands-on sessions on Git, docker containers, UI principles, web frameworks, and programming languages.

Hackathons

Exciting overnight hacknights where we sit together in the labs, brainstorm, drink tea, and build prototypes.

Timeline & Milestones

Community Journey

How we started, how we grew, and where we are heading as a group.

JANUARY 2025

Community Kickoff

Formed by a small team of students who wanted to learn coding outside the textbook. Outlined goals: open code sharing, active peer workshops, and physical meetups.

APRIL 2025

First Linux Install Fest

Gathered 60+ students in the labs to learn operating system boot sequences, install Linux, and play around with command utilities.

OCTOBER 2025

Hacknight v1.0

Hosted an overnight coding hackathon with 100+ participants. Spent the night building projects, drinking tea, and code debugging.

FEBRUARY 2026

TinkerSpace Cooperation

Partnered with TinkerHub's learning networks, syncing pathways to enable advanced topics like web development, systems, and design.
