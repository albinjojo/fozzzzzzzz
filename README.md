# FOSS AJCE Community Website

Repository for the Free and Open Source Software (FOSS) Community website of Amal Jyothi College of Engineering (AJCE).

This website serves as the primary portal and showcase for the student community, detailing events, partnership networks, and open-source initiatives on campus.

---

## Project Purpose

The website is designed to:
* **Promote Open Source:** Raise awareness of software freedom, Linux installations, and collaborative software development.
* **Showcase Events:** Highlight hands-on workshops and student-led hackathons.
* **Detail Partnerships:** Document active affiliations with the FOSS United Foundation and ICFOSS (Government of Kerala).
* **Introduce the Team:** List student organizers, volunteers, and faculty coordinators.
* **Gallery Showcase:** Feature a gallery of student activities, workshops, and maker spaces.

---

## Design and Features

The application is built using a Neo-Brutalist design language:
* **Tactile Aesthetics:** Employs high-contrast borders (2px solid) and flat offset shadows.
* **Torn Paper Dividers:** Uses SVG-based displacement filters to create realistic paper-tear dividers between sections.
* **OS-Window Image Cards:** Displays gallery images inside styled mockups of vintage desktop operating system windows, with randomized rotation angles.
* **Scroll Animations:** Integrated with GSAP, ScrollTrigger, and Lenis smooth scrolling for transitions and effects.

---

## Technology Stack

* **Markup:** Semantic HTML5
* **Styling:** CSS3 variables and layouts (Flexbox, Grid)
* **Icons:** [FontAwesome 6 Icons](https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.4.0/css/all.min.css)
* **Libraries:**
  * [Lenis](https://github.com/studio-freight/lenis) (Smooth Scroll)
  * [GSAP & ScrollTrigger](https://greensock.com/gsap/) (Animations)
* **Fonts:** Space Grotesk, Outfit, Playfair Display, and Fira Code (Google Fonts)
